# V2.2 — Midnight Blue

Perubahan utama:

- Seluruh identitas warna dark crimson diubah menjadi kombinasi midnight blue, royal blue, cyan, dan indigo.
- Warna biru dijaga konsisten dari hero, showcase, detail project, contact, footer, sampai admin panel.
- Semua kartu project sekarang memiliki ukuran, rasio gambar, tinggi konten, dan footprint grid yang sama.
- Featured project tidak lagi mengambil dua kolom agar susunan portfolio lebih rapi.
- Judul, paragraf, metadata, dan teks kartu dirapikan melalui line-height, letter-spacing, wrapping, dan batas baris yang lebih konsisten.
- Asset SVG project dan sertifikat ikut disesuaikan ke palet biru.
- Animasi dan fungsi JavaScript dari V2.1 tetap dipertahankan.
