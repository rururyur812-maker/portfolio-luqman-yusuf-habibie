# Portfolio Luqman Yusuf Habibie — V2.2 Midnight Blue

Website portfolio statis dengan animasi JavaScript, halaman detail project, contact form lokal, serta admin panel berbasis localStorage.

## Cara membuka

1. Ekstrak file ZIP.
2. Buka folder `portfolio-luqman-v2-blue`.
3. Klik dua kali `index.html`.

Tidak membutuhkan CMD, Node.js, npm, build process, atau server.
